---
title: Cloudflare edge
description: Put an edge in front of any origin.
---

Cloudflare is an edge, not an origin: it fronts whichever provider runs your app.

```json title="ocel.json"
{
  "$schema": "https://ocel.dev/schema/0.0.1-alpha.0/ocel.schema.json",
  "slug": "my-app",
  "provider": { "name": "aws" },
  "edge": { "kind": "cloudflare" },
  "apps": [{ "name": "web", "path": "." }]
}
```

The token and the account id come from `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` in the environment, not from the config.

Hostname records go into the origin provider's own DNS unless you say otherwise. Write
them into Cloudflare instead:

```json title="ocel.json"
{
  "$schema": "https://ocel.dev/schema/0.0.1-alpha.0/ocel.schema.json",
  "slug": "my-app",
  "provider": { "name": "aws" },
  "edge": { "kind": "cloudflare" },
  "dns": { "kind": "cloudflare" },
  "apps": [{ "name": "web", "path": "." }]
}
```

Dev mode resolves real resources on every machine once the project is linked. That is what the [console](/docs/console) adds.
