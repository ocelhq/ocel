---
title: Cloudflare edge
description: Put an edge in front of any origin.
---

Cloudflare is an edge, not an origin: it fronts whichever provider runs your app.

```json title="ocel.json"
{
  "$schema": "https://ocel.dev/schema/0.0.0/ocel.schema.json",
  "slug": "my-app",
  "provider": "aws",
  "edge": "cloudflare",
  "apps": [{ "name": "web", "path": "." }]
}
```

The token and the account id come from `CLOUDFLARE_API_TOKEN` and `CLOUDFLARE_ACCOUNT_ID` in the environment, not from the config.

On a [VPS](/docs/providers/vps) or [Google Cloud](/docs/providers/gcp), Cloudflare runs no
worker: it forwards each hostname to the origin through a proxied record. The origin answers
only what arrives with the certificate your zone presents to origins (zone-level
authenticated origin pulls, with a certificate of your own rather than Cloudflare's shared
one). If the zone has none, ocel mints one good for a year, has every origin trust it, then
uploads it and turns zone-level pulls on. A month before a certificate ocel minted expires,
the next deploy mints its successor the same way: origins trust both, the zone switches, and
the certificate it replaced is deleted. To retire a leaked key sooner, delete that
certificate from the zone; the next deploy of each project mints and trusts a new one. A
promote purges what Cloudflare cached for the hostnames it flipped. The zone's SSL mode must
be Full or Full (strict). The token needs Zone Read, Zone Settings Read, DNS Edit, SSL and
Certificates Edit and Cache Purge on the zone, and Account Settings Read.

Hostname records go into the origin provider's own DNS unless you say otherwise. Write
them into Cloudflare instead:

```json title="ocel.json"
{
  "$schema": "https://ocel.dev/schema/0.0.0/ocel.schema.json",
  "slug": "my-app",
  "provider": "aws",
  "edge": "cloudflare",
  "dns": "cloudflare",
  "apps": [{ "name": "web", "path": "." }]
}
```

Dev mode starts the resources the app declares on your machine, linked or not, and reads its values from `.env`, or from the env source the config names for dev, with `.env.local` on top.
