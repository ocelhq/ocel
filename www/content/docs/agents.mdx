A coding agent such as Claude Code, Codex or Cursor can declare resources, run `ocel dev` and ship previews for you. The ocel skill teaches it how, and every command prints JSON it can act on.

## Install the skill

From the project root, either of:

```bash
npx skills add ocelhq/ocel --skill ocel
ocel skill install --yes   # the skill for this CLI's version
```

`ocel skill install` writes `.claude/skills/ocel` and `.agents/skills/ocel` at the project root, or under your home directory with `--global`. Without `--yes` it lists the files and writes nothing. `ocel doctor` warns when the CLI has moved past the installed copy; install again to update it.

## JSON output

With `--json`, or `OCEL_JSON=1`, nothing prompts. A command that returns data prints one line:

```json
{"ok":true,"data":{...}}
```

or, when it fails:

```json
{"ok":false,"error":{"code":"project.no_config","message":"...","hint":"ocel init --provider <id>","docsUrl":"https://ocel.dev/docs/errors/project.no_config"}}
```

A command that changes something, such as `ocel deploy`, prints one JSON event per line and ends with a `summary` event.

```bash
ocel env ls --json | jq -r 'if .ok then "ok" else .error.code end'
```

## Errors

Every error carries a stable `code`, a `hint` that resolves it when there is one, and a `docsUrl` to its page in the [error reference](/docs/errors). A command that needs a confirmation it cannot ask for fails with [`confirmation_required`](/docs/errors/confirmation_required) and changes nothing.

## Finding commands

The binary describes itself, so an agent never relies on a copied list:

| Command | Prints |
| --- | --- |
| `ocel help --json` | Every command, argument and flag, and whether each command changes anything |
| `ocel help <command> --json` | One command |
| `ocel schema <command>` | The JSON Schema of that command's `--json` output |

## Reading the docs

`https://ocel.dev/llms.txt` indexes these docs for agents. Every page is also served as markdown at its URL plus `.md`, such as `https://ocel.dev/docs/errors/project.no_config.md`.

## What stays with you

The skill tells the agent to bring you the plan and wait on production deploys, rollbacks, `ocel bootstrap`, `ocel projects destroy`, `--yes` on any of these, and anything that costs money. Nothing in the CLI enforces this: an agent with your credentials can run any command you can, so give it only credentials you would trust it with.
