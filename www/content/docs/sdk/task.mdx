---
title: Task
description: Background work, run once per trigger.
---

A task is a named function the app triggers to run in the background, once per trigger.

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts title="resources/index.ts"
import { task } from "ocel/task";

type Image = { url: string };

export const resize = task("resize-image", {
  run: async (image: Image) => image.url.length,
});
```

</Tab>

<Tab value="Go">

```go title="resources/resources.go"
package resources

import (
	"context"

	"ocel.dev/task"
)

type Image struct {
	URL string `json:"url"`
}

var Resize = task.New("resize-image", func(ctx context.Context, image Image) (int, error) {
	return len(image.URL), nil
})
```

</Tab>

<Tab value="Python">

```python title="resources/__init__.py"
import ocel


@ocel.task("resize-image")
async def resize(image: dict, ctx: ocel.RunContext) -> int:
    return len(image["url"])
```

</Tab>

<Tab value="Rust">

```rust title="src/main.rs"
#[derive(serde::Serialize, serde::Deserialize)]
struct Image {
    url: String,
}

#[ocel::task(name = "resize-image")]
async fn resize(image: Image, _run: &ocel::Run) -> Result<usize, ocel::RunError> {
    Ok(image.url.len())
}
```

</Tab>

</Tabs>

## Triggering

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts
const run = await resize.trigger({ url }, { delay: "5m" });
```

</Tab>

<Tab value="Go">

```go
run, err := resources.Resize.Trigger(ctx, resources.Image{URL: url}, task.Delay(5*time.Minute))
```

</Tab>

<Tab value="Python">

```python
run = resize.trigger({"url": url}, delay=timedelta(minutes=5))
```

`trigger_async` is the awaitable twin.

</Tab>

<Tab value="Rust">

```rust
let run = resize.trigger(Image { url }).delay(Duration::from_secs(300)).await?;
```

</Tab>

</Tabs>

`run.id` (`run.ID` in Go) names the run. `delay` is at most 30 days, and a payload at most 256 KiB of JSON. Other trigger options: `ttl`, `idempotencyKey`, `debounce`, `key` (orders the runs of an `ordered` task), `lane`, `maxAttempts`, `tags` and `metadata`. `batchTrigger` starts several runs in one call.
