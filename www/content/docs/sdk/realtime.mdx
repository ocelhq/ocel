title: Realtime
description: Typed channels that browsers subscribe to and your server publishes on.

A realtime resource is a set of channel patterns. Your app's handler authorizes each subscribe and publish and signs a short-lived token; the transport only checks the token.

<Tab value="TypeScript">

```ts title="resources/realtime.ts"
import { realtime } from "ocel/realtime";
import { z } from "zod";

export const rt = realtime("app", {
  authorize: async (req) => {
    const session = await getSession(req.headers);
    return session ? { id: session.user.id } : null;
  },
  channels: {
    "orders/:orderId": {
      schema: z.object({ status: z.string() }),
      subscribe: async ({ auth, params }) => ownsOrder(auth.id, params.orderId),
    },
    status: { schema: z.object({ text: z.string() }), subscribe: "public" },
  },
});
```

```ts title="app/api/realtime/route.ts"
import { createRealtimeHandler } from "ocel/realtime/next";
import { rt } from "../../../resources/realtime";

export const { GET, POST, OPTIONS } = createRealtimeHandler(rt);
```

`ocel/realtime/express` and `ocel/realtime/hono` export the same function.

```ts
await rt.publish("orders/:orderId", { params: { orderId }, body: { status: "shipped" } });
```

<Tab value="Go">

```go title="resources/realtime.go"
package resources

import (
	"net/http"

	"ocel.dev/realtime"
)

type Caller struct {
	ID string `json:"id"`
}

var Live = realtime.New("app", realtime.Authorize(func(r *http.Request) (*Caller, error) {
	return readCaller(r)
}))

type OrderEvent struct {
	Status string `json:"status"`
}

type OrderParams struct {
	OrderID string `realtime:"orderId"`
}

var Orders = realtime.NewChannel[OrderEvent, OrderParams](Live, "orders/:orderId",
	realtime.ChannelSubscribe(func(ctx *realtime.SubscribeContext[Caller, OrderParams]) (bool, error) {
		return ownsOrder(ctx.Auth.ID, ctx.Params.OrderID), nil
	}),
)
```

```go
http.Handle("/api/realtime", resources.Live.Handler())

err := resources.Orders.Publish(ctx, resources.OrderParams{OrderID: id},
	resources.OrderEvent{Status: "shipped"})
```

`realtime.ChannelSubscribePublic()` opens a channel to anyone; `realtime.ChannelPublish(rule)` lets browsers publish.

<Tab value="Python">

```python title="resources/__init__.py"
from pydantic import BaseModel

import ocel

live = ocel.realtime("app", authorize=read_caller)


class OrderEvent(BaseModel):
    status: str


@live.channel("orders/:orderId", schema=OrderEvent)
def orders(ctx: ocel.RuleContext) -> bool:
    return owns_order(ctx.auth.id, ctx.params["orderId"])
```

```python
serve_realtime = live.asgi()  # or live.wsgi(); mount at /api/realtime

orders.publish({"status": "shipped"}, orderId=order_id)
```

The decorated function is the subscribe rule. `subscribe="public"` opens a channel to anyone; `publish=rule` lets browsers publish. A refused publish raises `ocel.RealtimePublishError`.

<Tab value="Rust">

```rust title="src/main.rs"
use ocel::realtime::{Realtime, SubscribeContext};

#[derive(serde::Serialize, serde::Deserialize, schemars::JsonSchema)]
struct OrderEvent {
    status: String,
}

#[allow(non_snake_case)]
#[derive(ocel::Channel)]
#[ocel(realtime = "app", pattern = "orders/:orderId", event = OrderEvent, schema)]
struct Orders {
    orderId: String,
}

fn build_realtime() -> Realtime {
    Realtime::builder("app")
        .authorize(|request: Arc<ocel::realtime::Request>| async move {
            Ok::<_, Infallible>(read_caller(&request))
        })
        .subscribe::<Orders>(|ctx: SubscribeContext<Caller, Orders>| async move {
            Ok::<_, Infallible>(owns_order(&ctx.auth.id, &ctx.params.orderId))
        })
        .build()
        .expect("the realtime resource this app declares")
}
```

```rust
let rt = build_realtime();
let app = axum::Router::new().nest_service("/api/realtime", ocel::realtime::axum::router(rt.clone()));

rt.publish(&Orders { orderId: id }, &OrderEvent { status: "shipped".into() }).await?;
```

Enable the `realtime` feature, plus `axum` for the router and `schemars` for `schema`. `#[ocel(public)]` opens a channel to anyone; `#[ocel(publish)]` plus `.publish::<C>(rule)` lets browsers publish.

In the browser:

```ts title="app/live.ts"
import { createRealtimeClient } from "ocel/realtime/client";
import type { rt } from "../resources/realtime";

const live = createRealtimeClient<typeof rt>({ url: "/api/realtime" });

const stop = live.subscribe("orders/:orderId", { params: { orderId } }, (event) => {
  console.log(event);
});
```

For a Go, Python or Rust backend, run [`ocel generate`](/docs/cli/generate) and type the client with `createRealtimeClient<RealtimeResources["app"]>` from the generated `ocel-realtime.d.ts`.

## Where it runs

| Target | Transport | A revoked caller keeps an open subscription for at most |
| --- | --- | --- |
| `ocel dev` | Ocel gateway inside `ocel dev` | the dev server's lifetime |
| AWS | AppSync Events | 24 hours |
| Google Cloud | Ocel gateway on Cloud Run | 60 minutes |
| VPS | Ocel gateway in a container on the box | the next deploy |

Rules run on subscribe and on every reconnect, not on events to an open subscription. The browser client reconnects on its own and re-authorizes every live subscription in one request.

## On AWS

- One AppSync Event API per environment; each realtime resource is a channel namespace on it.
- A Lambda authorizer (128 MB, arm64) checks each connect and subscribe token, uncached, so an expired token is never admitted.
- Only the server publishes, signed with the app's IAM role, which reaches only its own namespace. A browser publish goes through your handler's `publish` rule.
- Each resource's Ed25519 signing key is a Secrets Manager secret, deleted with no recovery window when the resource or environment goes.
- Billed: AppSync operations and connection minutes, authorizer calls, one secret per resource. The cost estimate prices them.
- An account bootstrapped before realtime existed has its bootstrap stack updated before the first realtime deploy.

## On Google Cloud

- One Cloud Run service per environment runs the gateway for every resource. Browsers connect to its `run.app` address from any origin; the tokens are the only check.
- A publish is retried only on 429 or when no connection opened: at most once delivery.
- Signing keys live in Secret Manager. The gateway rereads the public keys every 30 seconds, so adding a resource rolls no revision.
- One instance (1 vCPU, 1 GiB) holds 950 sockets; the next gets 503 and retries.
- A gateway upgrade rolls a revision: sockets on the old one get no events until they reconnect.
- Billed per second a socket is open: about $70 a month for one always-connected browser, plus requests and egress.
- The deploy credentials need `roles/secretmanager.editor` on their namespace's realtime secrets ([what to grant](/docs/providers/gcp#what-to-grant)). A project bootstrapped before realtime existed is refused until you bootstrap again.
