---
title: KV
description: A key-value store of its own, typed by key pattern.
---

Each KV store is its own Valkey instance. Entries name the key patterns the app uses and the shape of each value: `text`, `counter`, `json`, `list` or `set`.

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts title="resources/index.ts"
import { kv } from "ocel/kv";

export const cache = kv("cache", {
  entries: { session: kv.text("session/:id") },
});
```

</Tab>

<Tab value="Go">

```go title="resources/resources.go"
package resources

import "ocel.dev/kv"

var Cache = kv.New("cache")

var Session = kv.NewText[string](Cache, "session", "session/:id")
```

</Tab>

<Tab value="Python">

```python title="resources/__init__.py"
import ocel

cache = ocel.kv("cache")
session = cache.text("session", "session/:id")
```

</Tab>

<Tab value="Rust">

```rust title="src/main.rs"
#[derive(ocel::KvKey)]
#[ocel(pattern = "session/:id", text)]
struct Session {
    id: String,
}

#[derive(ocel::Resources)]
pub struct Infra {
    #[ocel(entries = [Session])]
    pub cache: ocel::Kv,
}
```

</Tab>

</Tabs>

Store options: `version` (`"8"` or `"9"`), `eviction` (default `noeviction`) and `memory`, such as `"256mb"`; in Go, `kv.Version`, `kv.Eviction` and `kv.Memory`. An entry can declare a `ttl`.

## Reading and writing

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts
await cache.session.set({ id: "abc" }, token, { ttl: "1h" });

const token = await cache.session.get({ id: "abc" }); // undefined when missing
```

</Tab>

<Tab value="Go">

```go
err := resources.Session.Set(ctx, "abc", token, kv.TTL(time.Hour))

token, err := resources.Session.Get(ctx, "abc") // kv.ErrMiss when missing
```

</Tab>

<Tab value="Python">

Install `ocel[kv]`. Every method has an `_async` twin.

```python
session.set(token, id="abc", ttl="1h")

token = session.get(id="abc")  # None when missing
```

</Tab>

<Tab value="Rust">

Enable the `kv` feature.

```rust
let entry = resources.cache.entry(Session { id: "abc".into() });
entry.set(token).ttl(Duration::from_secs(3600)).await?;

let token = entry.get().await?; // None when missing
```

</Tab>

</Tabs>

A write without `ttl` uses the entry's own. `"keep"` keeps the key's current TTL and `null` clears it (Go `kv.KeepTTL()` / `kv.NoTTL()`, Rust `.keep_ttl()` / `.clear_ttl()`).
