title: Topic

Every consumer of a topic receives every message sent to it.

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts title="resources/index.ts"
import { topic } from "ocel/topic";

type Order = { id: string };

export const orders = topic<Order>("orders");

export const audit = orders.consumer("audit", async (order) => {
  console.log("order placed", order.id);
});
```

</Tab>

<Tab value="Go">

```go title="resources/resources.go"
package resources

import (
	"context"
	"log"

	"ocel.dev/topic"
)

type Order struct {
	ID string `json:"id"`
}

var Orders = topic.New[Order]("orders")

var Audit = Orders.Consumer("audit", func(ctx context.Context, order Order) error {
	log.Println("order placed", order.ID)
	return nil
})
```

</Tab>

<Tab value="Python">

```python title="resources/__init__.py"
import ocel

orders = ocel.topic("orders")


@orders.consumer("audit")
async def audit(order: dict, ctx: ocel.RunContext) -> None:
    print("order placed", order["id"])
```

</Tab>

<Tab value="Rust">

```rust title="src/main.rs"
#[derive(Clone, serde::Serialize, serde::Deserialize)]
struct Order {
    id: String,
}

#[derive(ocel::Resources)]
pub struct Infra {
    pub orders: ocel::Topic<Order>,
}

#[ocel::consumer(topic = Infra::ORDERS)]
async fn audit(order: Order, _run: &ocel::Run) -> Result<(), ocel::RunError> {
    println!("order placed {}", order.id);
    Ok(())
}
```

</Tab>

</Tabs>

## Sending

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts
const messageId = await orders.send({ id: "o_123" });
```

</Tab>

<Tab value="Go">

```go
messageID, err := resources.Orders.Send(ctx, resources.Order{ID: "o_123"})
```

</Tab>

<Tab value="Python">

```python
message_id = orders.send({"id": "o_123"})
```

`send_async` is the awaitable twin.

</Tab>

<Tab value="Rust">

```rust
let message_id = resources.orders.send(Order { id: "o_123".into() }).await?;
```

</Tab>

</Tabs>

A payload is at most 256 KiB of JSON. Send options: `delay` (up to 30 days), `idempotencyKey`, `key` (orders the messages of an ordered topic) and `lane`.
