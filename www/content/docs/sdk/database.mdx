---
title: Database
description: A Postgres database, handed to your app as a connected pool.
---

Declaring a database in a [discovery folder](/docs/configuration#discoverypaths) hands back the
pool your app queries through. The deploy provisions the database and delivers its connection
under the name you declared.

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts title="resources/index.ts"
import { postgres } from "ocel/postgres";

export const db = postgres("main");
```

`db` is a [`pg`](https://node-postgres.com) pool: `await db.query("select * from documents")`.

</Tab>

<Tab value="Go">

```go title="resources/resources.go"
package resources

import "ocel.dev"

var DB = ocel.Postgres("main")
```

`DB.Pool(ctx)` opens a [pgx](https://github.com/jackc/pgx) pool on its first call and returns the
same one after.

</Tab>

<Tab value="Python">

```python title="resources/__init__.py"
import ocel

db = ocel.postgres("main")
```

Install `ocel[postgres]`, then `await db.fetch("select * from documents")`, or take the
[asyncpg](https://magicstack.github.io/asyncpg/) pool with `await db.pool()`.

</Tab>

<Tab value="Rust">

```rust title="src/main.rs"
#[derive(ocel::Resources)]
pub struct Infra {
    pub main: ocel::Postgres,
}

#[ocel::main]
fn main() {
    let resources = Infra::load().expect("the resources this app declares");
}
```

With the `postgres` feature, `resources.main.pool().await?` is a [sqlx](https://github.com/launchbadge/sqlx) `PgPool`.

</Tab>

</Tabs>
