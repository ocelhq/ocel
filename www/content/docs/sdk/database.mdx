The Postgres major version is `17` unless declared: `{ version: "16" }`, `ocel.PostgresVersion("16")`, `version="16"`, `#[ocel(version = "16")]`.

## Querying

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

`db` is a [`pg`](https://node-postgres.com) pool.

```ts
const { rows } = await db.query("select * from documents where id = $1", [id]);
```

</Tab>

<Tab value="Go">

`Pool` opens a [pgx](https://github.com/jackc/pgx) pool on the first call and returns the same one after.

```go
pool, err := resources.DB.Pool(ctx)
if err != nil {
	return err
}
rows, err := pool.Query(ctx, "select * from documents where id = $1", id)
```

</Tab>

<Tab value="Python">

Install `ocel[postgres]`. `await db.pool()` is the [asyncpg](https://magicstack.github.io/asyncpg/) pool.

```python
rows = await db.fetch("select * from documents where id = $1", id)
```

</Tab>

<Tab value="Rust">

Enable the `postgres` feature. `pool()` is a [sqlx](https://github.com/launchbadge/sqlx) `PgPool`.

```rust
let pool = resources.main.pool().await?;
let rows = sqlx::query("select * from documents where id = $1")
    .bind(id)
    .fetch_all(pool)
    .await?;
```

</Tab>

</Tabs>

Every SDK also exposes the connection as a URL: `db.connectionString`, `DB.ConnectionString()`, `db.connection_string`, `resources.main.connection_string()?`.
