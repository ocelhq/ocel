## Reading and writing

A key is a path. Each segment is non-empty and neither `.` nor `..`; `.ocel/` is reserved.

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts
import { uploads } from "../resources";

await uploads.put("reports/q3.pdf", bytes, { contentType: "application/pdf" });

const report = await uploads.get("reports/q3.pdf");
if (report) console.log(report.info.size, await report.text());

for await (const object of uploads.list({ prefix: "reports/" })) {
  console.log(object.key, object.etag);
}

await uploads.delete(["reports/q3.pdf", "reports/q2.pdf"]);
```

- `get` and `head` return `null` for a missing key.
- Also: `copy`, `list().page({ cursor })`, and `cacheControl` / `metadata` on writes.

</Tab>

<Tab value="Go">

```go
err := resources.Uploads.WriteAll(ctx, "reports/q3.pdf", data,
    ocel.ContentType("application/pdf"))

report, err := resources.Uploads.ReadAll(ctx, "reports/q3.pdf")

for object, err := range resources.Uploads.List(ctx, ocel.Prefix("reports/")) {
    if err != nil {
        return err
    }
    log.Println(object.Key, object.ETag)
}

err = resources.Uploads.Delete(ctx, "reports/q3.pdf", "reports/q2.pdf")
```

- `NewReader` and `NewWriter` stream one object.
- A missing key returns `ocel.ErrObjectNotFound`.

</Tab>

<Tab value="Python">

```python
from resources import uploads

uploads.put("reports/q3.pdf", data, content_type="application/pdf")

with uploads.get("reports/q3.pdf") as report:
    print(report.info.size, report.bytes())

for entry in uploads.list(prefix="reports/"):
    print(entry.key, entry.etag)

```

- `uploads.open(key, "rb")` opens an object as a binary file.
- Every method that reaches the store has an `_async` twin (`public_url` does not).
- A missing key raises `ocel.ObjectNotFound`.

</Tab>

<Tab value="Rust">

use futures::StreamExt;

resources.uploads

- `put`, `get`, `list`, `signed_url` and `signed_upload` return builders; awaiting one runs it.
- `reader` and `writer` stream one object.
- A missing key fails with `Error::NotFound`.

### Conditional writes

| Condition | TypeScript | Go | Python | Rust |
| --- | --- | --- | --- | --- |
| Only if the key is empty | `ifNoneMatch: "*"` | `ocel.IfNotExists()` | `if_not_exists=True` | `.if_not_exists()` |
| Only while the etag matches | `ifMatch: etag` | `ocel.IfMatch(etag)` | `if_match=etag` | `.if_match(etag)` |

An unmet condition refuses the write.

## Public buckets

```ts title="resources/index.ts"
export const assets = bucket("assets", { public: true });

assets.publicUrl("logo.svg"); // https://storage.example.com/logo.svg
```

Go `ocel.BucketPublic()`, Python `public=True`, Rust `#[ocel(public)]`.

- The address comes from the domain bound to the project. With no domain, `publicUrl` fails.
- In TypeScript `publicUrl` exists only on a public bucket; the other SDKs fail at the call.
- AWS and Google Cloud refuse `public`; serve through your app or a signed url.

## Signed urls

```ts
const read = await uploads.signedUrl("reports/q3.pdf", {
  expiresIn: 300,
  download: "q3.pdf",
});

const write = await uploads.signedUpload("reports/q4.pdf", {
  expiresIn: 300,
  maxSize: 10 * 1024 * 1024,
  contentType: "application/pdf",
});
```

- `signedUpload` returns `url`, `method`, signed `headers` and POST `fields`; send them unchanged.
- Both need a domain bound to the project.
- A store bound with an `endpoint` (such as R2) signs no POST policy and refuses `maxSize`; check the size after upload instead.

## Browser uploads

```ts title="resources/index.ts"
import { bucket, uploader } from "ocel/bucket/next";
import { z } from "zod";
import { pg } from "./postgres";

export const uploads = bucket("uploads", {
  allowedOrigins: ["https://app.example.com"],
  uploaders: {
    document: uploader(
      {
        input: z.object({ ownerId: z.string() }),
        middleware: ({ input }) => ({ ownerId: input.ownerId }),
      },
      {
        accept: ["image/*", "application/pdf"],
        limits: { maxFileCount: 5, maxFileSize: 10 * 1024 * 1024 },
        path: { prefix: "documents/", randomSuffix: true },
        onUploadComplete: async ({ metadata, file }) => {
          await pg.query("insert into documents (key, owner_id) values ($1, $2)", [
            file.key,
            metadata.ownerId,
          ]);
        },
      },
    ),
  },
});
```

```ts title="app/api/upload/route.ts"
import { createRouteHandler } from "ocel/bucket/next";
import { uploads } from "../../../resources";

export const { GET, POST } = createRouteHandler(uploads);
```

```ts title="app/upload-button.tsx"
import { createUploadClient } from "ocel/bucket/client";
import type { uploads } from "../resources";

const client = createUploadClient<typeof uploads>({ url: "/api/upload" });

await client.upload("document", { files, input: { ownerId } });
```

- `middleware` returns the uploader's `metadata`; throwing refuses the request.
- `ocel/bucket/hono` and `ocel/bucket/express` export the same pair; `ocel/bucket` is framework-neutral.
- An unknown uploader name or a mismatched `input` is a compile error.
- `upload` resolves once `onUploadComplete` has run: it polls from 1 s (`pollIntervalMs`), doubling to 15 s, for up to 15 minutes (`maxPollMs`).
- The store answers only `allowedOrigins` and the hostnames bound to the project.
- From Go, Python or Rust, hand the page a `signedUpload` target.

## Limits

| | Limit |
| --- | --- |
| Server write in one request | 16 MB; larger writes go as 8 MB parts, 4 in flight, stored once the last lands |
| Browser upload | One request: the store's single-request limit (5 GB on S3). Cap with `maxFileSize` or `maxSize` |
| List page | 1000 objects |
| User metadata | 2 KB per object |
| Signed url `expiresIn` | 7 days; longer is clamped |

## A bucket in a store you already run

On any provider, bind a declared bucket to an S3-compatible bucket you run (R2, Hetzner, AWS) and Ocel uses it instead of provisioning one.

```ts tab="TypeScript" tab-group="config" title="ocel.config.ts"
import { defineConfig } from "ocel/config";
import awsProvider from "ocel/providers/aws";

export default defineConfig({
  slug: "my-app",
  provider: awsProvider(),
  bindings: {
    bucket: {
      uploads: {
        endpoint: "https://${CF_ACCOUNT_ID}.r2.cloudflarestorage.com",
        region: "auto",
        bucket: { $env: "UPLOADS_BUCKET" },
        prefix: "uploads/",
        accessKeyId: { $env: "R2_ACCESS_KEY_ID" },
        secretAccessKey: { $env: "R2_SECRET_ACCESS_KEY" },
        publicBaseUrl: "https://cdn.acme.com/uploads",
      },
    },
  },
  apps: [{ name: "web", path: "." }],
});
```

```json tab="JSON" title="ocel.json"
{
  "$schema": "https://ocel.dev/schema/ocel.schema.json",
  "slug": "my-app",
  "provider": "aws",
  "bindings": {
    "bucket": {
      "uploads": {
        "endpoint": "https://${CF_ACCOUNT_ID}.r2.cloudflarestorage.com",
        "region": "auto",
        "bucket": { "$env": "UPLOADS_BUCKET" },
        "prefix": "uploads/",
        "accessKeyId": { "$env": "R2_ACCESS_KEY_ID" },
        "secretAccessKey": { "$env": "R2_SECRET_ACCESS_KEY" },
        "publicBaseUrl": "https://cdn.acme.com/uploads"
      }
    }
  },
  "apps": [{ "name": "web", "path": "." }]
}
```

| Field | Use |
| --- | --- |
| `accessKeyId`, `secretAccessKey` | Variables set with `ocel env set`; the app never sees them. Scope the key to this bucket. |
| `prefix` | Every key goes under it. |
| `pathStyle: true` | For a store with no wildcard DNS. |
| `publicBaseUrl` | Used as written, with the key appended. Required when the code sets `public`. |

`$env` on `bucket` or `prefix` gives each preview its own. Keyed by `production` or `preview`, a binding serves only that tier.

Each deploy checks that the bucket answers, that its CORS allows every `allowedOrigins` entry, and, for `public`, that anyone may read under the prefix. A mismatch refuses the deploy; a rule the key cannot read is a warning.

## On a VPS

- One RustFS container per environment holds every bucket, on a docker volume. Browsers reach it at `storage.<domain>`; until a domain is bound, signed urls, browser uploads and public objects are refused.
- Binding or releasing a hostname updates the allowed origins at once.
- The store stops signing writes while the volume has less than 1 GiB or 10% free.
- Dropping the last bucket deletes the container, its volume and every object. Back up first.
- A [transform](/docs/transforms#on-a-vps) can change the container. Two buckets patched differently are refused: gate the rule on the environment.

<Callout>
  The box's store is only as durable as its disk. [Bind a bucket](#a-bucket-in-a-store-you-already-run)
  to a store you trust for data you cannot lose with the machine.
</Callout>

## On Google Cloud

- Each bucket is its own Cloud Storage bucket, with CORS from `allowedOrigins`.
- Only the apps that bind it can read and write. Access is per app across a tier: `web` in one preview can reach another preview's `web` buckets.
- Signed urls are signed through IAM by the app's account; no key exists.
- Abandoned multipart uploads are aborted after a day; upload sessions are deleted a day after their last write.
- `ocel destroy`, or removing the bucket from code, deletes the bucket and its objects.

## On AWS

- Each bucket is its own S3 bucket, with CORS from `allowedOrigins`. A function beside it records browser uploads.
