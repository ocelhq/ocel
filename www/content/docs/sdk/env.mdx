---
title: Env
description: The variables and secrets your app reads, typed.
---

Declaring env names the variables your app reads and the type of each. A variable of the secret
class is read on every access, so a rotated value takes effect without a restart.

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts title="resources/env.ts"
import { defineEnv } from "ocel/env";
import { z } from "zod";

export const env = defineEnv({
  GREETING: { class: "plain", schema: z.string().default("hello") },
  API_KEY: { class: "secret" },
});
```

</Tab>

<Tab value="Go">

```go title="resources/resources.go"
package resources

import "ocel.dev"

var Env = ocel.Env[struct {
	Greeting string      `ocel:"GREETING,default=hello"`
	APIKey   ocel.Secret `ocel:"API_KEY"`
}]()
```

`Env.APIKey.Value()` reads the secret.

</Tab>

<Tab value="Python">

```python title="resources/__init__.py"
import ocel

class Env(ocel.Env):
    greeting: str = "hello"
    api_key: ocel.Secret
```

`Env().api_key.value` reads the secret.

</Tab>

<Tab value="Rust">

```rust title="src/main.rs"
#[derive(ocel::Env)]
struct Env {
    #[ocel(default = "hello")]
    greeting: String,
    api_key: ocel::Secret,
}

#[ocel::main]
fn main() {
    let env = Env::load().expect("the variables this app reads");
}
```

`env.api_key.value()?` reads the secret.

</Tab>
