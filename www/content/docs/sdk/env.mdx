---
title: Env
description: The variables and secrets your app reads, typed.
---

Declare the variables the app reads and the type of each. A secret is read on every access, so a rotated value applies without a restart.

Each value is set per tier with `ocel env set`, or [published by your own
infrastructure](/docs/environments#values-your-infrastructure-publishes).

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts title="resources/env.ts"
import { defineEnv } from "ocel/env";
import { z } from "zod";

export const env = defineEnv({
  GREETING: { class: "plain", schema: z.string().default("hello") },
  API_KEY: { class: "secret" },
});
```

</Tab>

<Tab value="Go">

```go title="resources/resources.go"
package resources

import "ocel.dev/env"

var Env = env.MustDefine[struct {
	Greeting string     `ocel:"GREETING,default=hello"`
	APIKey   env.Secret `ocel:"API_KEY"`
}]()
```

</Tab>

<Tab value="Python">

```python title="resources/__init__.py"
import ocel

class Env(ocel.Env):
    greeting: str = "hello"
    api_key: ocel.Secret
```

</Tab>

<Tab value="Rust">

```rust title="src/main.rs"
#[derive(ocel::Env)]
struct Env {
    #[ocel(default = "hello")]
    greeting: String,
    api_key: ocel::Secret,
}

#[ocel::main]
fn main() {
    let env = Env::load().expect("the variables this app reads");
}
```

</Tab>

</Tabs>

## Reading

<Tabs groupId="lang" persist items={["TypeScript", "Go", "Python", "Rust"]}>

<Tab value="TypeScript">

```ts
import { env } from "../resources/env";

env.GREETING; // "hello" unless set
env.API_KEY;
```

A missing or invalid value throws `EnvValueError`.

</Tab>

<Tab value="Go">

```go
resources.Env.Greeting
resources.Env.APIKey.Value()
```

`env.MustDefine` panics with `*env.ValueError` when a value is missing or invalid; `env.Define` returns the same error instead. A `Secret` prints as a redaction.

</Tab>

<Tab value="Python">

```python
env = Env()
env.greeting
env.api_key.value
```

A missing or invalid value raises `ocel.EnvValueError`.

</Tab>

<Tab value="Rust">

```rust
env.greeting;
env.api_key.value()?;
```

`Env::load()` fails when a value is missing or invalid.

</Tab>

</Tabs>
