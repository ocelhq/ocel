---
title: provider.unavailable
description: The provider process did not start.
---

Each provider runs as a separate process that ships with the CLI. This one failed to start, exited before it was ready, or did not become ready in time. The message carries the cause, and the provider's stderr when it printed any.

## Fix

Run the command again. If it keeps failing, reinstall the CLI so the provider binary is whole, and run `ocel doctor` to see what is wrong on this machine.
