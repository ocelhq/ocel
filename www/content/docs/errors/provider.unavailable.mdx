---
title: provider.unavailable
description: The provider did not start, or could not be reached.
---

Each provider runs as a separate process that ships with the CLI, or, for a project that deploys to Ocel Cloud, as a service Ocel Cloud runs. The process failed to start, exited before it was ready or did not become ready in time; or the provider answered that it, or a service behind it, could not be reached or did not answer in time. The message carries the cause, and the provider's stderr when it printed any.

## Fix

Run the command again. If it keeps failing, reinstall the CLI so the provider binary is whole, and run `ocel doctor` to see what is wrong on this machine.
