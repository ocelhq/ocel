---
title: bootstrap.missing
description: The account has no Ocel infrastructure for this tier.
---

A deploy needs the one-time bootstrap in your account, and this tier does not have it. The message says whether the account has none or has the other tier's.

## Fix

Run the command in the error's `hint`: `ocel bootstrap production` or `ocel bootstrap preview`, with the features the project needs when it names some. Then run the command again. In a terminal, Ocel offers to do this for you.
