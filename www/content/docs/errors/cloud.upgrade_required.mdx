---
title: cloud.upgrade_required
description: Ocel Cloud no longer serves this release of the CLI.
---

The project deploys to Ocel Cloud, so the command reached Ocel Cloud's provider service, and it answered that it no longer serves the release of the CLI that called it. Every call names the CLI's version, and Ocel Cloud serves the releases it still runs a provider for. The message is Ocel Cloud's own and names the releases it serves.

## Fix

Upgrade the CLI the way you installed it (see [install](/docs/quick-start#install)), and run the command again.
