---
title: sdk.version_mismatch
description: The SDK in your project is not a release this CLI works with.
---

An SDK works with a CLI of the same major release; before 1.0, of the same minor; and in 0.0.x, of the same release exactly. The SDK your project depends on is outside that range for the CLI you ran, so Ocel refuses to build against it.

## Fix

Install the SDK at the CLI's version. The error's `hint` is the command for your language, for example `npm i ocel@<version>`, `uv add ocel==<version>`, `cargo add ocel-sdk@<version>` or `go get ocel.dev@v<version>`. Or install the CLI release that matches the SDK.
