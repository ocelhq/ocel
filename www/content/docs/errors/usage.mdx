---
title: usage
description: The command line did not parse.
---

The command, its arguments or its flags were wrong before the command began to run: an unknown flag, a missing argument or a bad value. The error's `hint` carries the command's usage line.

`ocel env`, `ocel bootstrap` and `ocel connector` also raise it when run without a subcommand: they print their help and exit with code 1.

## Fix

Run the command with `--help` and compare it with the usage line in the error. For a command that needs a subcommand, pick one from the help it printed.
