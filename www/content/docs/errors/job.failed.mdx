---
title: job.failed
description: The job running the command on a runner failed.
---

The command ran as a job on a runner, because it was run with `--remote` or the project names no provider, and the job failed. The message names the job's own error code and message, and links the deployment's page in the console.

## Fix

Open the page in the console to read the job's log, fix what it names, and run the command again.
