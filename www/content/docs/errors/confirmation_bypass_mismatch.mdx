---
title: confirmation_bypass_mismatch
description: The destroy bypass variable is set, but not to the thing being destroyed.
---

`OCEL_DESTROY_BYPASS_CONFIRMATION` skips a destructive command's confirmation only when its value is the name of what the command is about to destroy. Here it names something else, and with no terminal to ask on, the command stops.

## Fix

Set the variable to the exact name the message gives, pass `--yes`, or run the command in a terminal, where a mismatched value falls back to the prompt.
