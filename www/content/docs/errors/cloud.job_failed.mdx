---
title: cloud.job_failed
description: The job running the command on Ocel Cloud failed.
---

The project deploys to Ocel Cloud, so `ocel deploy`, `ocel preview up` and `ocel build` ran as a job there, and the job failed. The message names the job's own error code and message, and links the job's page in the console.

## Fix

Open the job's page in the console to read its log, fix what it names, and run the command again.
