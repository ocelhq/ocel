---
title: provider.not_found
description: The provider has no record of what the command named.
---

The provider answered that it has no record of what the command named, such as a preview, a promotion or a project. The message is the provider's own and names what it could not find.

## Fix

Check the name against what the provider lists, such as `ocel preview ls`, `ocel promotions ls` or `ocel projects`, and run the command again with one it has.
