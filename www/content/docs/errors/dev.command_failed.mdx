---
title: dev.command_failed
description: The command that ocel dev or ocel run started exited with an error.
---

`ocel dev` and `ocel run` start your app's command and wait for it. That command exited with a non-zero status, and the CLI exits with the same code. Ocel itself did not fail: the command's own output says why it stopped.

## Fix

Read the command's output above the error, fix what it reports, and run it again.
