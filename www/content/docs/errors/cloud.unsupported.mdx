---
title: cloud.unsupported
description: The command does not run on Ocel Cloud yet.
---

The project names no provider and you are logged in to a console that offers Ocel Cloud, so the project deploys to Ocel Cloud. This release of the CLI cannot yet run the command there. For `ocel deploy`, `ocel preview up` and `ocel build`, the message names the source it uploaded.

## Fix

To run the command against your own account, name a provider in the project's config. See [configuration](/docs/configuration).
