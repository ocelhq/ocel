---
title: input_required
description: A command needs a value it cannot ask for.
---

The command needs a value you did not pass, and this run has no terminal to ask on, or is writing `--json`. The command stops and changes nothing.

## Fix

Pass the value the error's `hint` names, or run the command in a terminal and answer the prompt. For example:

- `ocel init`: `--provider <id>` or `--option name=value`
- `ocel link`: a project slug, or `--create`
- several organizations: `--org <slug>`
