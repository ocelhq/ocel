---
title: "ocel run"
description: "Run a one-off command with your project's resource connections."
---

```bash
ocel run [--env <environment>] -- <command> [args...] [flags]
```

<include>../../cli/run.mdx</include>

## Arguments

| Argument | Takes |
| --- | --- |
| `[--env]` | Optional |
| `<environment>` | Required |
| `<command>` | Required |
| `[args]...` | Optional, and repeatable |

## Flags

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--env` | `string` |  | Run against a deployed environment instead of dev resources: production, or preview for the current branch's preview |

Every command also takes the [global flags](/docs/cli#global-flags).

## Behaviour

- Changes state.
