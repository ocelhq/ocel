---
title: "ocel bootstrap"
description: "Set up the shared infrastructure deploys run on."
---

```bash
ocel bootstrap <command>
```

## Commands

| Command | What it does |
| --- | --- |
| [`ocel bootstrap destroy`](/docs/cli/bootstrap/destroy) | Tear down an environment with nothing deployed in it |
| [`ocel bootstrap preview`](/docs/cli/bootstrap/preview) | Set up or update the preview environment |
| [`ocel bootstrap production`](/docs/cli/bootstrap/production) | Set up or update the production environment |
