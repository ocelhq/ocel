---
title: "ocel bootstrap status"
description: "Show every part of a bootstrap: who added it, who uses it, what it costs idle and whether it is current."
---

```bash
ocel bootstrap status [production|preview] [flags]
```

Reads both environments unless one is named. `--resources` lists what each part holds.

## Arguments

| Argument | Takes |
| --- | --- |
| `[production\|preview]` | Optional |

## Flags

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--resources` | `bool` | `false` | List the resources each part holds |

Every command also takes the [global flags](/docs/cli#global-flags).

## Behaviour

- Read-only: it changes nothing.
- Prints data on stdout. Under `--json` it prints one result envelope, whose JSON Schema `ocel schema bootstrap status` prints.
