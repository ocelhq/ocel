---
title: "ocel bootstrap preview"
description: "Set up or update the preview environment."
---

```bash
ocel bootstrap preview [flags]
```

A bootstrap only ever builds up: each run brings its base current and adds every part a project here was refused for. `--remove` takes a part down, whichever added it, and refuses while a project here uses it unless `--force`.

Logged in to a console from a checkout linked to it, a run asks whether that console may deploy the environment here and adds the console-trust part that lets it, then records the identity it made in the console; `--remove` console-trust takes that trust down.

Every run prints the changes it would make before asking; `--dry` prints them and stops.

## Flags

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--dry` | `bool` | `false` | Print the changes and stop, applying nothing |
| `--force` | `bool` | `false` | Remove a part projects here still use |
| `--remove` | `string` |  | Comma-separated set of parts to take down; nothing goes unless it is named here |
| `-y, --yes` | `bool` | `false` | Consent in advance to any confirmation this command would ask for |

Every command also takes the [global flags](/docs/cli#global-flags).

## Behaviour

- Changes state.
- Asks before it changes anything: `--yes` consents in advance, and `--dry` prints what it would change and stops.
- Under `--json` it prints its run events as NDJSON, one per line, and `ocel schema bootstrap preview` prints the JSON Schema of one line.
