---
title: "ocel init"
description: "Make this directory deployable."
---

```bash
ocel init [slug] [flags]
```

<include>../../cli/init.mdx</include>

## Arguments

| Argument | Takes |
| --- | --- |
| `[slug]` | Optional |

## Flags

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--format` | `string` |  | Write the config as ts, json or yaml — the same document in each; ts needs node, and is the default only in a project built with it |
| `--lang` | `string` |  | Language of this project (go, rust, python, node), when the manifests do not say |
| `--option` | `stringArray` |  | Provider option whose value is text, as name=value; repeat it for each. On a terminal, init asks for any the provider cannot deploy without |
| `--provider` | `string` |  | Provider this project deploys through |

Every command also takes the [global flags](/docs/cli#global-flags).

## Behaviour

- Changes state.
- Prints data on stdout. Under `--json` it prints one result envelope, whose JSON Schema `ocel schema init` prints.
