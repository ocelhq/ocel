---
title: "ocel domain"
description: "Manage production hostnames and the global preview domain."
---

```bash
ocel domain
```

Manage this project's production hostnames, and the bootstrap-wide domain every project's previews are served on.

`add`, `rm`, `ls` and `status` read this project's domains.production; no command edits it. `use` and `release` take `--preview` and set the wildcard every previewed project is served on, at "&lt;project&gt;--&lt;preview&gt;[--&lt;app&gt;].&lt;domain&gt;". A project that declares its own domains.preview keeps it.

## Commands

| Command | What it does |
| --- | --- |
| [`ocel domain add`](/docs/cli/domain/add) | Provision certificates, edge and DNS for this project's production hostnames |
| [`ocel domain ls`](/docs/cli/domain/ls) | List this project's production hostnames, or the global preview domain with `--preview` |
| [`ocel domain release`](/docs/cli/domain/release) | Stop serving previews on the global preview domain |
| [`ocel domain rm`](/docs/cli/domain/rm) | Unbind the production hostnames this project no longer declares |
| [`ocel domain status`](/docs/cli/domain/status) | Show each production hostname's certificate, records and what is outstanding |
| [`ocel domain use`](/docs/cli/domain/use) | Serve every project's previews on this wildcard |
