---
title: "ocel domain ls"
description: "List this project's production hostnames, or with --preview the global domain and the projects served on it."
---

```bash
ocel domain ls [flags]
```

## Flags

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--preview` | `bool` | `false` | List the global preview domain and the projects served on it instead of this project's own hostnames |

Every command also takes the [global flags](/docs/cli#global-flags).

## Behaviour

- Read-only: it changes nothing.
- Prints data on stdout. Under `--json` it prints one result envelope, whose JSON Schema `ocel schema domain ls` prints.
