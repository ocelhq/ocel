---
title: "ocel connector"
description: "Manage the connector the console reads this target's variables through."
---

```bash
ocel connector <command>
```

<include>../../../cli/connector.mdx</include>

## Commands

| Command | What it does |
| --- | --- |
| [`ocel connector add`](/docs/cli/connector/add) | Put a connector on this target and pair it with the console |
| [`ocel connector rm`](/docs/cli/connector/rm) | Take the connector off this target and forget it in the console |
| [`ocel connector status`](/docs/cli/connector/status) | Say what the console has registered for the connectors of this organization |
