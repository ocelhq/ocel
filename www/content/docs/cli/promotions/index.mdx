---
title: "ocel promotions"
description: "Manage production promotions."
---

```bash
ocel promotions
```

## Commands

| Command | What it does |
| --- | --- |
| [`ocel promotions ls`](/docs/cli/promotions/ls) | List production promotions |
| [`ocel promotions prune`](/docs/cli/promotions/prune) | Reclaim old production promotions |
