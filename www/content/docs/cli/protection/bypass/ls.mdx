---
title: "ocel protection bypass ls"
description: "List the ids of the bypass secrets, without revealing them."
---

```bash
ocel protection bypass ls [flags]
```

## Flags

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--preview` | `bool` | `false` | Act on the previews instead of production |

Every command also takes the [global flags](/docs/cli#global-flags).

## Behaviour

- Read-only: it changes nothing.
- Prints data on stdout. Under `--json` it prints one result envelope, whose JSON Schema `ocel schema protection bypass ls` prints.
