---
title: "ocel skill"
description: "Manage the ocel skill coding agents read."
---

```bash
ocel skill
```

The skill teaches a coding agent how to declare resources with the ocel SDK, run ocel commands, read their `--json` output and leave production to you.

## Commands

| Command | What it does |
| --- | --- |
| [`ocel skill install`](/docs/cli/skill/install) | Write the ocel skill where coding agents look for it |
