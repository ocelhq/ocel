---
title: "ocel preview protection bypass create"
description: "Create a bypass secret for this project's previews, and print it once."
---

```bash
ocel preview protection bypass create
```

Only the secret is printed on stdout, so it can be piped into a CI secret store. Nothing shows it again. Send it in the x-ocel-preview-bypass header; `ocel preview protection bypass revoke` ends it. Creating a secret leaves the password and the login sessions it opened alone.

## Behaviour

- Changes state.
- Prints data on stdout. Under `--json` it prints one result envelope, whose JSON Schema `ocel schema preview protection bypass create` prints.
