---
title: "ocel preview protection password set"
description: "Replace this project's preview password with one read from stdin."
---

```bash
ocel preview protection password set
```

The password is read from stdin, never from an argument, so it stays out of shell history and process listings. It needs at least 12 characters and at most 256 bytes. The old password and every login session end, as with `rotate`:

```bash
printf '%s' "$PREVIEW_PASSWORD" | ocel preview protection password set
```

## Behaviour

- Changes state.
- Under `--json` it prints one result envelope on stdout, whose JSON Schema `ocel schema preview protection password set` prints.
