---
title: "ocel preview protection sync"
description: "Publish this project's recorded preview credentials to its edge again."
---

```bash
ocel preview protection sync
```

Every change is recorded first and then published to the edge that serves the project's previews. When an edge could not be reached the change stays recorded, `ocel preview protection` shows the edge as pending, and this publishes the record again. It is safe to run any time, and changes nothing the edge already holds.

## Behaviour

- Changes state.
- Under `--json` it prints one result envelope on stdout, whose JSON Schema `ocel schema preview protection sync` prints.
