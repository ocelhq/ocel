---
title: "ocel logs"
description: "Print the logs of this project's apps."
---

```bash
ocel logs [app...] [flags]
```

<include>../../cli/logs.mdx</include>

## Arguments

| Argument | Takes |
| --- | --- |
| `[app]...` | Optional, and repeatable |

## Flags

| Flag | Type | Default | Description |
| --- | --- | --- | --- |
| `--all-releases` | `bool` | `false` | Include releases still running but no longer promoted |
| `--environment` | `string` |  | Read this named preview environment instead of the one the current branch names (with `--preview`) |
| `--for` | `string` |  | Stop a `--tail` after this duration (30s, 5m) |
| `--grep` | `string` |  | Print only entries containing this text |
| `--level` | `string` |  | Minimum level to print: debug, info, warn or error |
| `-n, --lines` | `int` | `100` | Newest N entries to read, before `--level` is applied |
| `--preview` | `bool` | `false` | Read a preview instead of production |
| `--raw` | `bool` | `false` | Print messages as sent, without reading a level or fields out of them |
| `--since` | `string` | `1h` | Start of the window: a duration back from now (15m, 2h) or an RFC3339 time |
| `-t, --tail` | `bool` | `false` | Keep streaming new entries after the history |
| `--until` | `string` |  | End of the window, as `--since` (default: now) |

Every command also takes the [global flags](/docs/cli#global-flags).

## Behaviour

- Read-only: it changes nothing.
- Prints data on stdout.
