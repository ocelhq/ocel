---
title: "ocel projects"
description: "List, show and destroy the projects Ocel has deployed into this account."
---

```bash
ocel projects
```

<include>../../../cli/projects.mdx</include>

## Commands

| Command | What it does |
| --- | --- |
| [`ocel projects destroy`](/docs/cli/projects/destroy) | Permanently destroy a project in both tiers |
| [`ocel projects ls`](/docs/cli/projects/ls) | List the projects Ocel has deployed into this account |
| [`ocel projects show`](/docs/cli/projects/show) | Show a project's environments and every resource Ocel created for it |

## Behaviour

- Read-only: it changes nothing.
- Prints data on stdout. Under `--json` it prints one result envelope, whose JSON Schema `ocel schema projects` prints.
