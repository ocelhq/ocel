```bash
ocel logs
ocel logs web worker --since 15m --level warn
ocel logs --tail --for 5m
ocel logs --preview --grep timeout
```

Prints what your apps wrote to stdout and stderr, from your own provider account, the same way on
every provider. Run it in the project or pass `-c`; credentials come from your shell, as each
[provider's page](/docs/providers/aws) describes.

## What it reads

- **Apps:** all of them, or the ones you name. An undeployed name is refused, and the error lists
  the deployed ones.
- **Releases:** the one each app serves; `--all-releases` adds ones still running but no longer
  promoted.
- **Environment:** production; `--preview` reads the current branch's preview, as
  [`ocel preview`](/docs/cli/preview) resolves it, or the one `--environment` names.
- **Entries:** the newest `-n` (at most 10000) between `--since` and `--until`, oldest first.

`--level` applies after `-n`, so it can leave fewer lines, and drops lines whose level can't be
told: the one the message names, else the provider's severity (the provider's alone with `--raw`).

## Tailing

`--tail` prints the history, then streams until Ctrl-C or `--for`, exiting 0. It takes no value:
`ocel logs --tail 50` reads `50` as an app name. `--until` is refused with `--tail`, `--for`
without it. Notices that entries were left out or the stream reconnected go to stderr.

## Reading entries

On a terminal, entries are coloured lines in local time, errors boxed and long field values
shortened (`-v` expands them). A stack trace split across entries shows as one.

Piped, or with `--raw`, each is one plain line: UTC time, app (`web/http`, or `web/<worker>`), level
(`-` when unknown), message, fields as JSON.

No logging library needed: pino, bunyan, winston, slog, zap, structlog, tracing and logfmt are all
read, and any other line shows as written. Platform lines such as Lambda's `START` and `REPORT` are
dropped, and failures such as a timeout or running out of memory print as errors.

## Agents and CI

```bash
ocel logs --json --level error --since 30m   # recent errors, then exit
ocel logs --json --tail --for 60s            # watch through a smoke test, then exit 0
```

`--json`, or `OCEL_JSON=1`, prints one object per line on stdout and nothing else; stderr is NDJSON
too. A tail without `--for` runs until killed.

```json
{"type":"entry","time":"2026-10-04T09:12:03.512Z","app":"web","source":"http","release":"<release>","instance":"<instance>","stream":"stderr","level":"error","message":"{\"level\":\"error\",\"msg\":\"payment failed\",\"user\":\"u_42\"}","fields":{"user":"u_42"},"failure":false}
{"type":"notice","kind":"sampled","message":"120 entries were left out because the log store sampled them","omitted":120}
```

An entry has `type`, `time` (UTC), `app`, `source` (`http` or a worker), `release`, `instance`
(the function instance or container), `stream` (empty when unrecorded), `level` and `fields` (left
out when unknown or empty), `message` (as written) and `failure` (the provider reported a failure,
such as a timeout).

A notice has `type`, `message`, `omitted` (`0` unless `sampled`) and a `kind`:

| `kind` | Means |
| --- | --- |
| `caught_up` | End of the history. Without `--tail` the read stops here. |
| `sampled` | The log store left `omitted` entries out. |
| `source_gone` | A release's function or container, and its logs, no longer exist. |
| `reconnected` | The stream reopened; entries in between may be missing. |

## Provider limits

| Provider | Logs live in | Limits |
| --- | --- | --- |
| VPS | Docker's `local` log driver on the box | 100 MB per container (5 files of 20 MB, oldest dropped), gone when the container is pruned |
| AWS | CloudWatch Logs | `FilterLogEvents`: 5 to 25 calls a second per account and region (10 in most), shared with the AWS console. `--tail` polls every 2 s, backing off to 10 s, unless [`logs.liveTail`](/docs/providers/aws) is on |
| Google Cloud | Cloud Logging | `entries.list`: 60 a minute per project. Live tails: 10 open per project, 60,000 entries a minute each; skipped entries print a `sampled` notice. Quota refusals are retried three times |
