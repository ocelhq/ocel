# Security

Report a vulnerability privately: on the repository's **Security** tab, choose **Report a
vulnerability** ([direct link](https://github.com/ocelhq/ocel/security/advisories/new)).
Keep it out of public issues, pull requests and commits until a fix ships.

Include:

- the output of `ocel --version`, and the provider you deploy to;
- the steps or code that reproduce it;
- what an attacker reaches with it: which credential, account or data.

Redact your own secrets before you send logs.

Ocel is in alpha, so fixes land in the next release only.
